## Summary
The current architecture relies entirely on simulators and reference code. While the `edge_model_contract.json` is strictly validated (35/35 passing tests), the actual firmware has never been compiled, no `.tflite` model has been trained or deployed, and all MQTT traffic is generated by the `gateway_simulator.py`. Hardware deployment is currently entirely unverified.
